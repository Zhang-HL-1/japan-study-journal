## 刷题功能

- 题库暂为空，未预置示例题。预留微积分、线性代数、电路与模拟电子、信号与系统、电磁学、数字电子分类；题目接入后自动启用练习。学科与章节也会从题目数据自动发现。
- 按学科、章节、难度、题型或关键词筛选，支持顺序练习和随机练习。
- 单选题、数值题自动判题；数值题支持小数、科学计数法、分数及题目规定的误差。输入时不要带单位。
- 解答题展示参考推导，由使用者自评；正确率包含自评结果，不是官方评分。
- 提前查看客观题答案不计成绩；点击「重新作答」后可判题。
- 答错进入错题本，再次答对移出。错题题单不会在作答中突然跳题，点击「更新题单」刷新。
- 作答、收藏、笔记、练习天数和上次位置自动保存在当前浏览器的 `localStorage`，无账号、无云同步；清除浏览器数据会丢失记录。
- 可导出 JSON 备份，再在其他设备导入；导入前会提示替换当前记录，建议先备份。公开仓库不会收到个人练习记录。

## 扩充题库

题库位于 `questions.js`，所有题目都是静态数据，不依赖第三方服务。每题包含稳定的 `id`、`subject`、`chapter`、`difficulty`、`type`、`title`、`prompt`、`answerText`、`explanation`（步骤数组）及 `hint`。

- `choice`：添加 `options` 数组及从 0 开始的正确选项 `answer`。
- `numeric`：添加数值 `answer`、绝对误差 `tolerance`，可选 `unit`。
- `written`：参考解答配合自评，不做自动文本判分。

新增题目应使用独一无二的 ID；不要更换已发布题目的 ID，以免练习记录对应错误。`source` 字段填写来源：若加入有权使用的真题，请标明学校、年份和出处；原创题应明确标注原创。数学表达式使用 Unicode 文本，页面不依赖外部公式 CDN。

## 检查

`node --test tests/*.test.cjs` 可运行题库、判题逻辑与 DOM 模拟交互测试，无需安装依赖。DOM 模拟不代替真实浏览器的视觉布局检查；测试数据不会进入网站题库。
