# 院校资料汇总：第二阶段

以学校为入口，把已收录的考试范围、历史原卷、校区资料放在同一页。页面沿用暖白色、衬线标题与卡片风格。

- `schools.html`：23 所学校的目录，支持中文别名与日文名称搜索、按已收录校区地区筛选。
- `schools.html?school=waseda`：学校汇总、研究科资料入口、校区清单。链接保留实际研究科名称，不做历史名称推测映射。
- `q`、`region`：目录筛选写入网址；打开学校与返回目录保留筛选。快速切校支持浏览器返回。
- 考试范围、过去问、地图提供返回当前院校汇总的入口。

## 数据口径与维护

`school-hub-data.js` 是从三个现有目录生成的约 24 KB 索引，不包含考试原文或 PDF 内容。院校页不加载三个完整目录。
更新 `exam-scope-data.js`、`past-papers-data.js` 或 `campus-map-data.js` 后执行：

```sh
node scripts/build-school-index.cjs
```

CI 通过 `--check` 检查索引与目录同步。一般入试与留学生相关数量可能重叠；原卷按组计数，PDF 按每校唯一 URL 去重。核对日期表示已收录考试条目的日期范围，不代表所有资料已重新核验。

空白覆盖会明确标注。名古屋大学三个研究科的校区对应缺口继续保留；历史原卷中独有的研究科名称不与当前名称自动合并。
