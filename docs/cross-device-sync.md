# 跨设备同步

书桌收藏（`japan-study-journal:desk:v1`）和练习记录（`japan-study-journal:practice:v1`）可以镜像到你自己的一个私密 GitHub Gist。数据不进入本仓库，也不写入托福练习使用的 `atrium-toefl-progress.json` 或 `atrium-device-*.json`。

连接入口在「我的书桌」和「刷题练习」。考试范围、过去问页面只在后台同步收藏，设置仍回到书桌或刷题页。令牌保存在本机 `japan-study-journal.sync.github.v1`，不会放进进度 JSON。

每台设备使用同一个仅含 `gist` 权限的 classic token。Gist ID 留空时，会查找已有的、包含 `japan-study-journal-progress.json` 的私密 Gist；没有则新建。之后每台设备写入自己的 `japan-device-<id>.json`。读取时合并基线文件和全部设备文件。

本地更改约 1.5 秒后拉取、合并再上传。回到页面、恢复联网，以及页面可见时每 30 秒再检查一次。网络失败时本地记录保留，下次再试。

合并规则：

- 书桌收藏按资料键取较新的收藏时间，不因一份快照缺少某条就删掉另一份里的收藏。取消收藏后，若其他设备的快照仍保留该条，合并会把它带回。
- 练习次数和错误次数取较大值，重复同步不会累加。两台设备离线各自增加的次数不会相加。
- 作答结果在次数相同的时候，用较新的 `updated`；次数不同时，保留次数更多的那一边，避免较新的空记录盖掉已有作答。
- 原卷的「已练习」可以取消。较新的 `updated` 决定完成或未完成；笔记不会因为另一边是空字符串而被清掉。原卷完成状态仍然不计入正确率。
- 收藏标记和笔记各自带时间。较新的标记可以取消收藏；没有时间戳的旧笔记会留下来。
- 筛选和当前题目用各自的更新时间。相同时间下结果稳定，不随设备文件的先后改变。

第二台设备等第一台连接成功后，可以留空查找，或贴上页面上的 Gist ID。两台同时留空，可能会各自新建一份。
