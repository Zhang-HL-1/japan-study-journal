# 过去问选校与筛选布局

按用户反馈，将原来的学校长列表移至页面上方的“按校名快速选择（23所）”折叠区，采用与考试范围页一致的圆角校名按钮。折叠区保留中文别名／日文名称搜索，学校按钮不再附带拥挤的数量标签；悬停提示仍可查看收录组数。

左侧改为紧凑的“筛选真题”面板，依次提供学校、研究科、专攻、原卷年份与关键词。所有宽度均使用有完整样式的学校下拉框。右侧专注于结果数量、学校说明、原卷列表与阅读区。

快捷按钮和下拉框保持同步，切换学校清除研究科、专攻和年份条件；网址分享、刷新恢复、PDF 文件切换和收藏功能继续工作。手机端依次显示快捷入口、筛选面板和结果，展开的校名按钮自然换行，不另设内部滚动列表。
