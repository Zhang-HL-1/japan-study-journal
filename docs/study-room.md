# 练习室与过去问题库

练习室入口 `practice.html` 以两张等大的卡片引导选择：过去问题库 `past-papers.html` 与刷题练习 `drill.html`。两者同级，均可返回入口或切换到另一模块。

旧刷题页面迁到 `drill.html`，继续使用原来的 `questions.js`、`practice.js`、`practice-core.js` 和浏览器记录键 `japan-study-journal:practice:v1`。收藏、错题、笔记和导入导出不变。逐校导入完整过去问PDF，逐题刷题库仍为空。

## 过去问题库

- 大学名称和中文别名来自现有 `campus-map-data.js` 的大学目录，当前23所大学。
- 原卷目录独立存放在 `past-papers-data.js`，与逐题练习库分开；当前收录早稻田大学35组／41个PDF，东京理科大学61组／121个PDF，另有东京科学大学33组／49个PDF（含早期部分资料），另有上智大学6个题群入口／4个PDF，合计135组／215个原卷及补充PDF，另附1个待核验照片PDF。
- 研究科、专攻与原卷年份筛选只从实际录入的原卷产生，未录入时禁用，避免虚构年份、原卷或答案。
- 学校索引支持中文别名和日文全称；真题可按大学、研究科、专攻、原卷年份与AND关键词筛选，按年份从新到旧显示。
- 选择一份原卷后可阅读PDF、切换问题／答案文件、在新窗口打开；仓库中的PDF另提供下载。旧研究科名称按原卷保留，不改写为现行校区目录中的新名称。
- 学校筛选支持 `past-papers.html?school=utokyo` 等既有大学ID。空状态中的考试范围链接携带同一大学ID。

## 后续添加真题

把允许公开保存的PDF放在 `assets/past-papers/`，再向 `past-papers-data.js` 的 `papers` 数组添加元数据。也可使用学校官网HTTPS链接。下面是**格式示例，不能作为实际真题直接加入**：

```js
{
  id: 'school-program-exam-year', // 唯一且稳定
  universityId: 'utokyo', // 必须是既有学校ID
  title: '原卷上实际的试卷名称',
  graduateSchool: '原卷上实际的研究科名称',
  department: '原卷上实际的专攻名称', // 可选
  selectionName: '原卷上实际的选拔名称',
  examYear: 2025, // 实际举行考试的年份，不用入学年度替代
  subjects: ['原卷的实际考试科目'], // 可选
  files: [
    { label: '問題', kind: 'question', url: 'assets/past-papers/university/2025/questions.pdf' },
    { label: '解答', kind: 'answer', url: 'assets/past-papers/university/2025/answers.pdf' }
  ],
  sourceNote: '实际来源与适用范围的说明', // 可选
  sourceURL: 'https://学校官网/实际来源页面' // 可选
}
```

`files` 至少包含一个文件。`kind` 可为 `question`、`answer`、`other`。没有官方答案时不要填写答案文件；不要把其他年份、其他选拔或逐题练习答案当作原卷解答。多份文件可直接增加 `files`；若需要从指定PDF实际页开始阅读，可在文件对象添加正整数 `startPage`。

早大文件来源为用户Google Drive的“早稻田大学”文件夹，原目录与共享设置不修改。收录基幹、創造、先進理工学研究科的目标工程专业；排除数学／应用数学和物理学／应用物理学8份PDF。`paperYear`按卷面9月入学年索引，`originalYear`和`admissionYears`同时保留次年4月入学信息；不把封面修订标记写成考试日期。两份乱码文件按卷面确认为2014、2015年电子物理系统卷。2023年经营设计使用历史专攻名；订正页保留于完整原卷并提供单独入口。SHA-256及原目录对应关系见 `assets/past-papers/waseda-import-manifest.json`，用于后续逐校接续导入。

本地文件必须为 `assets/past-papers/` 内的PDF；外部文件与来源仅接受已收录大学官网HTTPS域名。页面采用文本节点展示目录内容，不把元数据作为HTML执行。测试用文件仅由浏览器测试服务器临时生成，不在正式目录或网站资源中。

## 视觉与动效

两幅原创插画参考Claude官网早期插画的视觉语言，以翻阅原卷与落笔解题的手势表达两个入口：粗细不规则的黑色笔触、纸白、陶土色块和轻微纸张颗粒。图片生成后转换为保留透明背景的WebP，并随仓库托管；未直接使用官网图片或品牌标识。入口有短暂的出现动效，悬停时卡片轻微抬升、插画倾斜、箭头移动。尊重 `prefers-reduced-motion`，键盘焦点可见，手机上两个入口纵向排列。学校索引在手机上使用可横向滚动的标签。

## 东京理科大学导入

Google Drive的“东京理科大学”与“东京理科大学ee”共313份PDF中，按既定专业范围选取148份，去除27份相同字节副本后保存121个PDF，组成61组。覆盖工学、創域理工、先進工学研究科的11个目标工程专攻，一般卷为2023—2025年度，外国人卷为2024—2025年度，电气历史卷为1997—2016的部分年度与2021年度。未声明全校或连续年度完整覆盖。学校官方学系表将国際火災科学归为建筑，故沿用排除规则；药学、纯数学／物理、化学、土木建筑及非修士／社会人资料不录入。

`paperYear`是原卷／档案入学年度，`examYear`及`examDates`只来自题页的实际举行日期。例如2023年度电气卷实际2022-07-22，2024年度外国人创域理工卷实际2024-01-10；不得把所有试卷标为夏季场次。未印年度的历史卷用`yearEvidence: source-directory`保留档案年度并在页面明确标注。2020夏入电磁卷与2021年度合册同为2020-07-23的考试，归入2021年度。

2004-1合册保留其他专攻英语并从第2页打开电气问题；2004-2实际上是平成10—17年度（1998—2005）手写电磁气学参考集，以非官方答案和对应页入口附在已有原卷年度下。原手写笔记日期不作考试日期。2024年度信息计算科学的订正页和2025年度材料卷原有非公开部分均保持完整原发布文件。字节SHA-256、原路径、排除清单见`assets/past-papers/tus-import-manifest.json`。


## 东京科学大学／原东京工业大学导入

入口为 `past-papers.html?school=science-tokyo`。收录电气电子系及旧电气电子工学／电子物理工学专攻共用专业笔试。33组包含24个完整实施年度（2001—2019、2021—2025）和9个部分年度（1990、1993—2000）；48个问题PDF，另附2025官方出题意图，合计49个有年度归属的PDF。未核验R03照片另设学校说明入口，不赋予考试年份，也不计作2020原卷。

本校 `paperYear` 与 `examYear` 均按实际实施年，入学年度另列；不改早大、东理的原年度规则。H22封面日期与22大修／历史官网年度冲突，2009实施为按2010入学推定，在原卷说明中保留冲突。H03—11部分合集37页原样保存，由7组共享并按实际PDF页码打开；第4—5页缺明确年度，不归入1991或1992。H12/H13各两张单页摘录依原资料库命名标注，缺全年完整资料。

历史研究科、专攻名称保留；原件扫描、批注、出题意图均不改写为官方答案。2020历史官网说明没有普通笔试，替代在线试验不公开。学校说明显示缺失年份与待核验入口。来源URL、字节大小、SHA-256、页数及归属见 `assets/past-papers/science-tokyo-import-manifest.json`。


## 上智大学导入

云盘“过去问／上智大学”的4个PDF全部原样保存：2025入学年度9月、2月问题各一册，解答／解答例各一册。9月实际2024-09-11，2月实际2025-02-16；`paperYear`保留2025入学年度，`examYear`及`examDates`分别记录实施年份／日期。两份解答合册与学校官方发布文件逐字节一致。

机械、电气电子、信息学三个理工基礎题群按各自问题与解答实际PDF页码设置入口，共6组共享4份PDF，不宣称6套独立试卷。所属仍为理工学研究科／理工学専攻，不把题群名称虚构为独立专攻，也不强行绑定志望领域。其余题群保留在原合册中；不为既定排除专业创建独立目录。2月机械问题合册第10页印有2024年度／2024-02-16旧页眉，原件保持，按题群封面归2025入学年度并说明冲突。

入口为 `past-papers.html?school=sophia`，校验值、来源与各题群起止页见 `assets/past-papers/sophia-import-manifest.json`。其他学校的后续导入顺序见 `docs/past-paper-imports.md`。
