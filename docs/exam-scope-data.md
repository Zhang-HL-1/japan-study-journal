# 考试科目与范围资料维护

当前已发布東京大学、京都大学、東京科学大学、早稲田大学、東京理科大学、大阪大学、東北大学、九州大学、北海道大学、慶應義塾大学、上智大学、神戸大学、名古屋大学、電気通信大学、筑波大学、一橋大学与横浜国立大学首批资料。`exam-scope-data.js` 的 `records` 仅录入经官方资料核验的入口；修士与从修士阶段入学的修士／博士一贯制项目必须明确区分。新增学校时同时更新 `catalog` 的学校说明，页面会随学校筛选切换覆盖范围与待处理说明。

每条记录对应一个「学校 + 研究科/学院 + 专攻/系/课程 + 官方选拔方式 + 入学年度」。一般入试与留学生选拔使用不同记录。英语项目保留真实官方名称，不能自动标成外国人专门入试；外国籍考生通过一般入试申请时，也不能把它改称独立留学生选拔。

字段：

| 字段 | 内容 |
| --- | --- |
| `id` | 稳定且唯一的字符串 |
| `universityId` | 学校 id；新增学校时也更新 `universities` |
| `graduateSchool` | 官方研究科/学院全称 |
| `department` | 官方专攻/系全称 |
| `course` | 可选，正式课程／教育研究分野名称；页面可按此项独立筛选 |
| `degreeProgram` | 可选，`master` 为独立修士，`integrated` 为从修士阶段入学的修士／博士一贯制；显示名称与编辑说明必须同步标明 |
| `admissionType` | `general` 或 `international`（后者为留学生相关选拔栏目，页面仍显示真实名称） |
| `selectionName` | 官方选拔名称原文 |
| `entryYear` | 资料适用入学年度/年月，不能与入试实施年份混淆 |
| `verifiedAt` | 本条资料实际核验日期 `YYYY-MM-DD` |
| `subjectsOriginal` | 可选，学校科目原文；保留必答/选答条件 |
| `scopeOriginal` | 可选，学校范围原文，不翻译、概括或扩展 |
| `conditionsOriginal` | 可选，原文条件/例外，不与科目拆开造成误读 |
| `originalLanguage` | 可选，默认 `ja`；英语文件使用 `en` |
| `internationalGeneral` | 一般选拔明确允许符合条件的海外学历者时设为 `true`，留学生栏目显示一般选拔标识 |
| `publicationStatus` | 可选，`pending` 案内待公布，`unverified` 范围待核验，`notice` 已公布变更预告但完整要项待公布，`closed` 修士招生停止通知 |
| `editorialNote` | 中文编辑说明，与官方原文分开显示 |
| `searchAliases` | 可选，非空字符串数组；经来源支持的专业常用称呼／中英文对应，只用于检索，不替代官方名称或考试原文 |
| `sources` | 非空数组，官方文件与对应页 |

每个 source 包含 `label`（原文件名/说明）、`url`（官方 HTTPS 地址）、`kind`（`pdf` 或 `page`），PDF 可增加从 1 开始的 `pdfPage`。`pdfPage` 使用 PDF 文件实际页序，不是纸面印刷页码。跨页表格应提供多条 source，或说明继续阅读相邻页。浏览器可能不支持 PDF 页码跳转；必须保留打开官方原文件的链接。

录入前检查最新募集要项、更新记录、招生停止/组织改编、修士与博士范围、一般与特殊选拔、外语成绩要求。没有公布新年度资料时不要移用旧年度科目。没有官方来源的学校/选拔不创建记录，不生成占位科目。有官方入口但案内待公布或专攻要求待核验的记录必须明确标注状态，不填猜测科目。仅有研究科共通要项时，应继续核对专攻别入试案内。

长表格、完整范围和长段落优先通过官方原文件对应页阅读，避免重新排版破坏选答关系；不得复制没有授权的长篇内容或重新分发整份官方 PDF。可录入事实性的科目名称和简短原文，并通过原始文件保留完整上下文。

当前允许的来源域名在 `exam-scope-core.js` 中维护，覆盖当前已收录学校的官方域名。新增学校时先核验其官方域名，再增加白名单。

机械两卷各3题50分、150换200；材料两卷各5题40分；航空海洋单元第二卷5选3，第一卷3题，均150换200；半导体两卷物理各200；电子信息卷Ⅰ线性代数／微积分各100，卷Ⅱ电磁／回路／逻辑／算法各50。没有把电子信息专业题误写成任选。面接研究经历与教育项目适性、专业卷／面接允许日英作答。学校未给所收录科目的教材章号，不从过去问推导考纲。

环境信息2027年4月第二次一般：题群选答笔试200、希望研究领域口述200、外部英语100。实际18页列题群但没有选答题数，记录不推定3选1。国费特别：仅口述＋书审，范围专攻科目、研究业绩与研究计划，没有统一外部英语成绩要求，不能复制一般英语规则或误称外国人一律免笔试。两种均事前与导师相互确认、预提交研究计划（日1000字／英500词）。申请2026年10月16–22日；一般11月12日笔试与口述（人数多可延13／14日），国费11月8–14日指定一天。须资格审查者9月窗口已结束；R8文件名不等于入学2026年度，封面明确令和9年4月。

先進実践学環一般按正式主题和导师所属学府／单元应考，禁止多个主题／教员申请；可另行报名其他学府，但学环资格不会自动变成该学府入学资格。口述检查跨领域研究意愿及研究计划妥当性。该轮6月1–5日申请、8月20–21日所收录理工／环境信息区分选考、9月30日结果已结束；[2026年10月7日公告](https://ynuifgs.ynu.ac.jp/news/news-2043/)明确2027年4月一般第二次不实施。三个主题各一个closed仅对应该期，不代表第一次或整个学环停止，旧冬季卷没有沿用。

### 英语材料与当前要项优先

理工／学环理工区分：TOEIC L&R公开或TOEFL iBT含Home，照片成绩、提交日向前两年。TOEFL需ETS直送0410及当天交本人报告，不用My Best；日本公开TOEIC可QR数字证打印。IP／ITP、Bridge／SW、PBT不接受。独自英语笔试仅数理科学单元，本批未把它赋予其他单元。

环境信息一般／学环环境信息区分：最新要项接受TOEIC L&R、TOEFL iBT含Home、IELTS；考试日起两年，单次Test Date。2026年1月后TOEFL可PDF打印，IELTS Online可TRF打印，日本公开TOEIC可QR打印，其余遵原件规定，口述结束前返还；不套理工ETS直送。第二次一般要项实际9–10页有新旧TOEFL评分与IELTS换算，优先于入口旧英语单页（后者未列IELTS及打印新规则），不由旧页覆盖新一期文件。换算满分阈值不当最低合格分。
