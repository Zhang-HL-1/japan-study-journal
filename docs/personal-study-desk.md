# 我的书桌：第三阶段

`desk.html` 将考试范围和过去问的收藏、最近阅读集中显示。两类详情页新增收藏按钮；首页与全站导航提供“我的书桌”。答案书架和学校收藏不在本阶段范围内。

- 收藏最多 200 条；最近阅读保留 50 条。重复打开同一条资料会更新时间和原卷文件序号。
- “接着读”进入最近一条资料。恢复具体考试条目／真题文件，不读取或保存原生 PDF 阅读器内部页码。
- 所有记录保存在当前浏览器 `japan-study-journal:desk:v1`；不自动跨设备同步，不使用既有刷题存储键。
- 可搜索标题、学校与研究科，按考试范围或真题筛选。
- 导出 JSON；导入验证完整文件后再合并，相同条目按类型和 ID 去重，保留已有收藏和较新的阅读记录。超过收藏上限或格式错误时不写入。
- 仅允许跳转到两个本站资料页，不接受导入文件的任意 URL。标题按纯文本显示。
- 浏览器存储不可用、损坏或空间不足时显示提示，不宣称保存成功；损坏的原内容可先原样导出，再经确认清空书桌。
- 清空最近阅读保留收藏；清空全部书桌记录需要页面确认，不影响刷题数据。
- 已移出目录的资料会在目标页提示重新检索，原收藏不自动删除。
