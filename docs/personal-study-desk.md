# 我的书桌：收藏

`desk.html` 集中显示考试范围与过去问的收藏。两类详情页提供收藏按钮，首页与全站导航提供“我的书桌”。

- 收藏最多 200 条，保存在当前浏览器 `japan-study-journal:desk:v1`，支持搜索、类型筛选、导出与导入合并。
- 打开资料或切换真题文件不再自动记录阅读，也不更新已收藏条目。真题收藏链接指向点击收藏时选择的原卷文件。
- 取消收藏会删除该条书桌记录；清空书桌需要页面确认，不影响刷题数据。
- 新版首次读取旧数据时，保留全部收藏及其资料链接，清理阅读时间和仅阅读未收藏的条目。此后普通浏览只读取收藏状态。
- 旧书桌备份仍可导入，只恢复收藏；阅读记录不会重新加入。导出也只包含收藏，损坏数据仍可原样导出以便修复。
- 导入验证完整文件后再合并；相同条目按类型和 ID 去重，保留已有收藏链接。格式错误或超出收藏上限时不写入。
- 书桌链接只指向本站资料页，标题以纯文本显示。目录条目移除时提示重新检索。
- 存储不可用、损坏或空间不足时明确提示，不宣称保存成功。
