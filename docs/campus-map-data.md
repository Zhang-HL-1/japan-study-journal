# 大学院地图：校区与来源

核对日期：2026-10-11。覆盖现有考试目录的23所大学、55处校区／研究基地，研究科名称与现有考试资料保持一致。地图数据独立保存，不修改1006条考试资料。

## 收录口径

地图表示修士及现有修士相关目录的主要教学研究校区，以及官网明确列出的部分研究基地；不使用学校本部或本科低年级校区替代大学院位置，不穷举校外协作机构与所有联合研究室。特定导师的基地通过说明区分，不能把一个点扩展为整个研究科。海事等目录里的既有停止募集资料保留原状态，地图位置不表示正在招生。

经纬度为依据官方地址及校区图设置的约略代表点，用于城市／校区级地理分布，不是官方精确坐标、导航目的地或考试会场。跨校区研究科在多个点中出现；units.detail说明每个点的对应范围，departments只在官网和既有目录能明确对应时填写。

## 特别核对

- 东京大学：数理科学在駒場I，新领域主体在柏；駒場II生研及东海仅标部分导师研究基地。
- 京都大学：工学主体在桂；信息学官网列吉田、宇治，能源官网列吉田、宇治、熊取。理学生物部分研究室另在犬山。
- 东京科学大学：2025环境报告书PDF实际第4页明确两校区均列六学院；横浜自2026-04-01替换原すずかけ台名称，旧名仍可搜索。不从学院的本科低年级所在地推定修士导师所在校区。
- 东京理科大学：当前工学研究科五专攻在葛饰；创域理工在野田，国际火灾科学官方另列神乐坂。
- 大阪大学：工学、信息科学主体在吹田，基础工学、理学在丰中；信息基础数学专攻现行官网地址是吹田，不沿用旧位置。
- 东北大学：生命科学官网列片平、川内、青叶山、星陵；青叶山仅把已明确的理学系研究栋对应北区，没有凭空将生命科学放在新青叶山。
- 早稻田：三理工在西早稻田，IPS在北九州，环境能源另有本庄和早稻田121号馆研究室，生命医科学部分研究室在TWIns。
- 庆应：理工矢上、SDM/KMD日吉协生馆、政策媒体湘南藤泽，分别标点。
- 明治：理工生田、先端数理中野，采用当前官网，不沿用旧生田说明。
- 法政：理工／信息小金井，设计工学系统设计田町；不替换成市谷富士见本部。中央国际信息另为市谷田町1-18。

## 交互与验证

- 鼠标滚轮、按钮、双击、触控双指缩放；拖动和平移；地图获得焦点后方向键移动、加减键缩放、0键全览。
- 邻近校区自动聚合，点击放大；达到缩放上限后可从同点列表选择，不丢失校区。
- 大学／研究科／地区／AND关键词筛选，空结果和重置。大学全称与既有中文别名、旧校区名均可搜索。
- 地图跳考试页使用school、graduate及适用的department参数；考试页仅接受现有目录值，再返回相同学校研究科的地图。
- `node --test tests/*.test.cjs` 180项测试。`CAMPUS_MAP_BROWSER=/absolute/chromium/path node tests/campus-map.browser.cjs` 验证真实浏览器交互，需安装Playwright。可设置CAMPUS_MAP_SCREENSHOTS输出截图。
