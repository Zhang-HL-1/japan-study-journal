# 逐题题库录入规范

`questions.js` 的 `QUESTION_BANK` 合并原卷练习与后续人工整理的逐题练习。已将过去问中所有含试题的目录组接入原卷练习：828 套、12 所学校、1,118 份不重复试题 PDF。831 个目录组中另外 3 组只有出题范围／出题意图／解答例，继续保留在过去问目录，不作为练习。学校、研究科／专攻和科目选项从练习数据自动生成。除下方東京理科大学 2025 年度的两套题目卡片外，逐题题库和练习册题目尚未添加。

## 练习方式

- 只刷历年真题 → 学校 → 研究科／专攻 → 全部学科：该专攻全部真题。
- 在上述条件中选电磁学：该专攻的电磁学真题。
- 只刷历年真题 → 全部学校 → 电磁学：各校电磁学真题。
- 只刷参考书／练习册 → 书籍 → 科目：指定书的练习。
- 混合练习：学校／专攻仅限制真题，书籍仅限制练习册；科目、章节、难度、题型及错题／收藏条件对所有来源生效。切换来源模式会清除学校、专攻和书籍条件，保留科目。

## 原卷练习维护

- 源数据仍为 `past-papers-data.js`，PDF 原件不移动、不转换、不重复上传。
- 运行 `node scripts/build-paper-practice.cjs` 生成 `paper-practice-data.js`；CI 通过 `--check` 防止目录与练习库不同步。
- 一套练习对应一个含 `kind: question` 的目录组，稳定 ID 为 `paper:<目录ID>`。同一 PDF 可被多个目录组引用，不把目录组数或文件数称作题目数。
- `type: paper` 保留原卷文件、打开页、目录结束页、科目原文、年度依据、实际考试日期、来源说明及补充资料。共享合册和部分资料仍按原目录说明使用；PDF 阅读器显示完整原件，不声称裁切到了某个科目或年度。
- 科目只根据目录 `subjects` 中明确出现的名称归类，支持日中电磁学等同义名称、合卷多科匹配。只有「専門科目」等笼统标签的原卷归为「科目待细分」，不根据专攻猜测其考题内容；此类原卷可能尚未进入某个单科结果。页面同时显示原始科目名称。
- 原卷可标记完成、取消完成、收藏、记笔记及备份。完成状态存储为 `completed`，不生成答题分数，不进入错题本；正确率仅统计逐题练习。
- `kind: answer` 仅作参考解答入口，`kind: other` 显示为补充资料。没有答案时明确提示，原卷不显示空的判题／答案按钮。
- 后续逐题拆分时新建逐题 ID，保留原卷练习 ID 与记录。

## 逐题数据格式

沿用 README 中的题干、答案、解析与题型字段，每题新增 `provenance` 对象。以下仅说明格式，不加载到正式题库。

```js
provenance: {
  kind: 'exam',
  school: '学校官方全称',
  graduate: '研究科官方全称',
  major: '专攻官方全称',
  year: '2025年度',
  number: '第2问 (1)',
  page: '3',
  label: '一般入试 · 夏季'
}
// 或参考书、练习册
provenance: {
  kind: 'workbook',
  book: '书名',
  edition: '第2版',
  chapter: '第3章',
  number: '3.2',
  page: '58',
  label: '作者 / 出版社'
}
// 原创题必须显式标注
provenance: { kind: 'original', label: '本站原创' }
```

真题必须填学校、研究科、专攻、年度及题号；书籍必须填书名、版次、章节／题号，页码按实际材料记录。不要推测未核验出处。`subject` 使用统一科目名（例如「电磁学」，包括电磁気学），跨校同科才能准确归组；原卷科目原文可补充在 `label`。专攻匹配使用学校、研究科、专攻的组合，避免同名专攻串校或串研究科。

每题在题干上方显示完整出处；旧的 `source` 文本仍显示，但不会自动归类成真题、练习册或原创。稳定 `id` 不可复用，旧作答记录无需迁移。学习记录仍只存当前浏览器，导入导出继续可用。

验证：`node --test tests/practice*.test.cjs`。测试样例不进入正式题库。
