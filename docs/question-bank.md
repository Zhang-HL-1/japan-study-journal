# 逐题题库录入规范

`questions.js` 的 `QUESTION_BANK` 是唯一逐题入口；过去问 PDF 目录与答案书架不会自动变成可评分题目。目前保持空题库。学校、研究科／专攻、书籍选项从已录入题目自动生成，没有题目时只显示「全部」。

## 练习方式

- 只刷历年真题 → 学校 → 研究科／专攻 → 全部学科：该专攻全部真题。
- 在上述条件中选电磁学：该专攻的电磁学真题。
- 只刷历年真题 → 全部学校 → 电磁学：各校电磁学真题。
- 只刷参考书／练习册 → 书籍 → 科目：指定书的练习。
- 混合练习：学校／专攻仅限制真题，书籍仅限制练习册；科目、章节、难度、题型及错题／收藏条件对所有来源生效。切换来源模式会清除学校、专攻和书籍条件，保留科目。

## 数据格式

沿用 README 中的题干、答案、解析与题型字段，每题新增 `provenance` 对象。以下仅说明格式，不加载到正式题库。

```js
provenance: {
  kind: 'exam',
  school: '学校官方全称',
  graduate: '研究科官方全称',
  major: '专攻官方全称',
  year: '2025年度',
  number: '第2问 (1)',
  page: '3',
  label: '一般入试 · 夏季'
}
// 或参考书、练习册
provenance: {
  kind: 'workbook',
  book: '书名',
  edition: '第2版',
  chapter: '第3章',
  number: '3.2',
  page: '58',
  label: '作者 / 出版社'
}
// 原创题必须显式标注
provenance: { kind: 'original', label: '本站原创' }
```

真题必须填学校、研究科、专攻、年度及题号；书籍必须填书名、版次、章节／题号，页码按实际材料记录。不要推测未核验出处。`subject` 使用统一科目名（例如「电磁学」，包括电磁気学），跨校同科才能准确归组；原卷科目原文可补充在 `label`。专攻匹配使用学校、研究科、专攻的组合，避免同名专攻串校或串研究科。

每题在题干上方显示完整出处；旧的 `source` 文本仍显示，但不会自动归类成真题、练习册或原创。稳定 `id` 不可复用，旧作答记录无需迁移。学习记录仍只存当前浏览器，导入导出继续可用。

验证：`node --test tests/practice*.test.cjs`。测试样例不进入正式题库。
