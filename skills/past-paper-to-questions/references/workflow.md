# 分批实施与恢复

## 开始时

1. 检查当前仓库、分支、未提交改动与项目指令；更新到最新 main 后新开任务分支，保留别人的更改。
2. 读取 `past-papers-data.js`（原始目录）和 `question-bank-index.json`（已接入逐题卷）。`paper-practice-data.js` 是整卷派生库，不能当逐题数据库。
3. 运行 inventory helper 生成队列，按 SHA 路径聚合重复 PDF 和所有 catalog 引用。当前基线 828 个含题目录组、1,118 份唯一 question PDF、目录标注合计 8,989 页；这不是全资料库 1,148 PDF / 9,182 页的统计口径。每次以最新脚本输出为准，不硬编码待办总数。
4. 清点任务范围：本次用户授权全部还是特定学校/科目。全量作业仍按小批执行；建议第一批 5–10 份结构相近的文件，验证后再决定批大小，不一次生成几千题后才检查。

## 依赖

Node.js 22 或更新版。Python 环境安装 `python3 -m pip install -r <skill>/scripts/requirements.txt`，可先创建 venv；不要改系统全局配置。CLI Playwright 只用于页面验收，仓库 CI 有安装命令。技能说明不依赖特定电脑或登录凭据。

## 单卷制作闭环

- 确认题目 PDF 真实页数、内容哈希、原始文件名、catalog 引用、年度语义及已知科目。
- 渲染完整相关页面（含封面、说明、订正和附图），建立“页 → 题号/续题/配图/非题目”的 coverage 草稿。文字层只能辅助定位。
- 大题与小问：有共用条件、图、连续证明链时保留为一题；如以后另做独立小问训练，建父子关系，不能把小问重复计入当前总题数。
- 扫描卷：保留高清原文裁图，按自然段拆成多个 region；不是整页截图冒充拆题。可搜索的文字/OCR 后续单独加，先保证不漏题、不改题。
- 图表：确定图号与题号归属，保留坐标轴、箭头、单位、图例和图号。题图横跨两页时按原顺序追加 region。
- 原题有误/订正：保留订正信息并建立关系。当前 schema 无法准确表达时记阻塞并先扩展小样，不静默改写扫描题图。
- 生成 draft 预览，看每张图，再回看完整原页检查首行/末行/小问/图号。校对完成才设 verified 并正式生成。
- 写单卷验收摘要与未解决项；通过数据测试和 390/800/1440 屏幕体验检查后加入总索引。

## 接入网站

Demo 是独立 `question-practice.html`，不改旧的 `questions.js` 空逐题数组，也不伪造 choice/numeric 答案字段。当前题型是“原题展示 + 自主练习完成标记”。

当多个单卷可用：先支持卷选择/学校科目筛选；再用轻量逐题索引跨卷组合。来源及题 ID 保持稳定。旧的 `practice:v1` 是整卷/旧测验记录，新的 demo 是 `question-demo:v1`。不要把练过一个大题写成整套已完成；不要把 demo completion 当 correct。

若未来需 Gist 同步，先制定逐题状态 schema 和按字段 timestamp 合并，加入 export/import 及旧版本迁移测试，再调整同步白名单。当前 demo 本地记录不能描述成跨设备同步。

## 阻塞与审计

在批次报告中记录 `pdf, catalogIds, page, issue, neededEvidence, status`。可选状态：pending / mapped / cropped / reviewed / integrated / blocked。inventory 输出只报告清单是否存在，不是该状态机的替代品。

至少记录：看不清符号、缺页、年度证据冲突、科目不明、跨页归属不明、订正关系未支持、版权/访问条件不明确等真实遇到的问题。不要臆测补图、自动补公式、随机分配科目。记录后继续无依赖的其他卷。

每批交付：处理的唯一 PDF 数、目录引用数、verified 大题数、对应的原卷页、生成物总大小、阻塞数量、已运行检查、PR/发布状态。只有每个纳入范围的内容都已映射并通过检查才称该 PDF 全部完成。合订本只处理一个年度时明确写部分完成。

## 多执行者交接

用户若分配给多个 AI：按不重叠的 PDF 哈希分组，分支独立，只由一个合并者更新总索引/队列；共享 PDF 的不同目录引用留给同一执行者。不要并发修改同一个 manifest 或覆盖别人的 PNG。用户未要求并行时无需创建代理。

## 可直接转交的任务提示

“请使用仓库 `skills/past-paper-to-questions/SKILL.md`，按 `docs/question-bank-rollout.md` 执行剩余过去问的逐题整理。先运行 inventory 生成最新队列，报告本批范围，再分批处理。严格保留日文原题、公式、图表、共用条件和来源；答案/解析暂不做。以神户大学电磁气学 demo 的真实 manifest 为样例，跨页题不要拆错。所有生成图对照原卷看图校验；疑点记录 blocked，不猜。每批运行数据和浏览器检查，提交可审阅改动，并明确已完成和剩余项。仅用 GitHub 插件/CLI，不用 computer use。合并、发布按本次授权执行。”
